### Brief Overview
We will be using this GitHub repository to learn about and practice collaborative coding and continuous integration!

### Getting Started
To start, you will need to make sure you have a "Git" installed on your device. Instructions will vary between operating systems, but [this page](https://docs.github.com/en/get-started/git-basics/set-up-git) should contain all the information you need. Once installed, please clone this repository using the following code...

```
git clone https://github.com/Autumn10677/practice_collaborative_coding.git
```

It's important that you do not move this folder once it has been downloaded, as it will break the link between Git and GitHub!

### What if I run into issues?
Feel free to leave a message under the "Isues" tab at the top of the page! If someone from our group knows how to help, then they will reply to your message there. Keeping issues in this one place makes it easier for other people to fix the issue if they run into it themselves!

### Where are slides posted?
After each group meeting, slides will be added to the 'slides/' folder! These may be updated if a typo or error is found afterwards.
